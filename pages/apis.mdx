# APIs

## Uniblock

Uniblock is the unified API and RPC infrastructure layer for ApeChain. One API key routes across NFT, token, transaction, and wallet endpoints with automatic provider failover and cost optimization built in. Direct API access to 55+ providers including Alchemy and QuickNode, across 300+ blockchains.

For teams that want to go further, the [Uniblock MCP server](https://docs.uniblock.dev/reference/unified-api/uniblock-mcp-setup) connects any compatible AI agent directly to ApeChain data through plain language prompts. No API key required to start.

**APIs available on ApeChain:**

- **[JSON-RPC](https://docs.uniblock.dev/reference/jsonrpc-docs/33139/ape-chain-overview#apechain-overview):** Full RPC access with automatic provider routing and redundancy.
- **[Token API](https://docs.uniblock.dev/reference/unified-api/api-overview-token):** Native and ERC20 token balances, metadata, and pricing for any address.
- **[NFT API](https://docs.uniblock.dev/reference/unified-api/api-overview-nft):** Ownership, metadata, and collection data for ERC721 and ERC1155 tokens.
- **[Transaction API](https://docs.uniblock.dev/reference/unified-api/api-overview-transaction):** Transaction history and details for any ApeChain address or contract.
- **[Wallet API](https://docs.uniblock.dev/reference/unified-api/api-overview-nft):** NFT balances, collections, holder status, transfers, and last active timestamp for any wallet address.
- **[MCP Server](https://docs.uniblock.dev/reference/unified-api/uniblock-mcp-setup):** AI agent access to all ApeChain endpoints. Plain language in, on-chain data out.
- **[Direct APIs](https://docs.uniblock.dev):** Direct access to 55+ providers including Alchemy, QuickNode, and more, across 300+ blockchains.
